# CRITICAL PRODUCT BEHAVIOR — THE ENTIRE WEBSITE MUST BE DRIVEN BY LIVE AVAKIN CHAT

This is extremely important.

The Live Avakin chat is NOT just one feature inside the website.

The ENTIRE application must behave as a live reactive interface driven by the captured Avakin chat.

Everything on the website should update automatically based on what is currently happening in the live chat.

Do NOT build static pages that require me to manually refresh or manually enter conversation information during normal use.

The live captured Avakin chat is the central data source of the entire application.

==================================================
1 — LIVE CHAT IS THE CORE OF THE WHOLE APP
==========================================

Once Live Avakin Assistant is started and the Avakin chat area is selected:

The entire application should enter a LIVE state.

Every approximately 1 second:

* check the selected Avakin chat area
* detect visual changes
* run OCR only when needed
* detect new messages
* identify speakers
* update conversation memory
* update player profiles
* update focus suggestions
* update reply suggestions
* update conflict detection
* update notifications
* update summaries
* update unread/new-reply counters
* update interaction statistics

All relevant areas of the application must react to the live chat automatically.

==================================================
2 — NO MANUAL REFRESH
=====================

I should NEVER need to press:

* Refresh
* Analyze again
* Update conversation
* Rescan chat

during normal Live Mode.

The website should update automatically while Live Mode is active.

Manual buttons may exist as fallback/debug tools only.

==================================================
3 — LIVE PLAYER LIST
====================

The player list must be generated from the captured live chat.

If OCR detects a new player:

Add that player automatically.

If a player sends another message:

Update:

* last message
* message count
* last activity
* interaction score
* whether they mentioned me
* whether they asked me something

Do not require me to manually create player profiles.

==================================================
4 — PLAYER PROFILES UPDATE LIVE
===============================

Every player's session profile should update automatically from live chat.

For example:

Ahmed speaks again

→ Ahmed profile updates automatically

Sara asks me a question

→ Sara profile shows an unanswered direct question

Faisal becomes rude

→ Faisal conflict state updates

This should happen without manual action.

==================================================
5 — FOCUS MODE MUST USE LIVE CHAT
=================================

Focus Mode must be continuously connected to live chat.

If I focus on Ahmed:

Every new Ahmed message should immediately:

* update Ahmed's context
* appear in his timeline
* influence Gemini replies
* increase priority
* update unanswered questions
* update current topic

If another player's message affects Ahmed's conversation:

include that relevant message too.

==================================================
6 — SMART FOCUS SUGGESTIONS UPDATE LIVE
=======================================

The website should continuously observe interaction patterns.

Examples:

If Ahmed keeps talking to me:
show:
"أحمد شكله يكلمك وايد تبيني أركز عليه"

If Ahmed stops interacting for a long time:
lower his priority naturally.

If another player starts talking to me repeatedly:
the Focus suggestion may update.

==================================================
7 — LIVE REPLY PANEL
====================

The main reply panel must always react to the latest relevant chat.

New relevant chat message:

→ update context
→ call Gemini
→ create 3 replies
→ add new reply group
→ keep old reply groups

Do not require me to press Generate after every incoming message.

Generate automatically for relevant new chat.

==================================================
8 — LIVE REPLY CAROUSEL
=======================

The reply carousel must continuously receive new reply groups.

Old reply groups remain available.

New reply groups are appended.

If I am on the latest group:
show the new one automatically.

If I am browsing an older group:
do not move me
show:
"X ردود جديدة"

The carousel must remain synchronized with the live conversation.

==================================================
9 — LIVE CONFLICT DETECTION
===========================

Conflict Mode must monitor the live chat automatically.

If conversation tone changes from normal to hostile:

show a live prompt such as:

"واضح إن الموضوع بدأ يحتد كيف تبيني نرد"

Options:

* بارد
* حازم
* تأديب محترم
* ساخر ذكي
* تجاهل
* إنهاء النقاش
* حفظ ماء الوجه

Do not require me to manually tell the app:
"this is an argument"

The system should detect it from context.
